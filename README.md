# Immersive Stalker - Custom Armor Animation Fix

Совместимость с кастомными моделями брони для **Immersive Stalker 0.1.114 Beta** (Anomaly 1.5.3).

Короче, замутил фикс для кастомных бронек. Аддон ориентируется на список моделей GFY и из-за этого некоторые другие модели может не пропускать, даже если нужные анимации у них есть. Теперь проверяется наличие самих анимаций, а не только модель по списку. Старую совместимость сохранил, лишнего не трогал. Проверил в игре, всё работает.

## Установка через MO2

1. Установить оригинальный Immersive Stalker 0.1.114.
2. Скачать ZIP хотфикса из папки `release`.
3. Установить ZIP отдельным модом в MO2.
4. Поставить патч ниже оригинала в левой панели MO2, чтобы `zone_actions.script` выигрывал конфликт.

Откат: просто отключить патч.

## Что изменено

- Для кастомного визуала проверяется наличие запрашиваемого движения через `game.motion_exists`, если метод доступен.
- Для продолжительности анимации используются данные активной модели, когда их удаётся прочитать.
- Старый каталог GFY сохранён для обратной совместимости.
- Если наличие движения подтвердить не получилось, неизвестная модель не запускает неподтверждённую анимацию.
- Проверки кешируются на время текущего визуала.

Точный список изменений: [`patches/zone_actions_custom_armor.patch`](patches/zone_actions_custom_armor.patch).

## Ограничения

Это не набор новых анимаций. Если движения в действительности нет, фикс его не создаёт. Проверено пользователем в его сборке Anomaly; совместимость со всеми кастомными моделями не гарантируется. Требуется оригинальный Immersive Stalker.

## Авторы

Оригинальный **Immersive Stalker**: **PrometeyGT**. Это сторонний неофициальный патч, не релиз исходного автора. Оригинальный код принадлежит его автору.
